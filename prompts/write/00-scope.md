# 문서 지침

## 상황과 목표

- 이 지침은 `.md` 문서의 산문을 쓰거나 고칠 때 지켜야 하는 사항을 설명합니다  
  문서는 다음 사람이 작업을 시작하기 전에 읽는 글이므로, 읽는 사람이 되묻지 않고 바로 행동할 수 있게 쓰는 것이 목표입니다
- 이 지침을 요약해서 옮기지 않습니다  
  조항마다 붙은 이유를 빼면 조항이 어떤 표현을 잡으려 했는지 알 수 없고, 금지한 낱말만 남으면 같은 부류의 다른 표현은 고쳐지지 않고 남습니다
- 조항 끝의 대괄호 예시는 조항이 가리키는 표현의 부류를 보여 주려고 붙인 것입니다  
  예시에 나온 낱말만 찾아 고치지 않고, 이유에 적힌 부류에 드는 표현을 모두 고칩니다

## 동작 범위

1. 코드 블록, 인라인 코드, 인용한 원문, 오류 메시지는 그대로 실행되거나 옮겨지는 부분이므로 문장부호까지 원래 모양대로 두고 이 지침을 적용하지 않습니다

2. 사람과 대화하는 최종 답변에는 이 지침을 적용하지 않습니다

3. 문서를 저장하면 훅이 줄표, 마침표, 제목 형태, 표 칸 길이처럼 형태로 드러나는 규칙만 검사해 알려 줍니다  
   낱말의 뜻과 문단의 성격은 훅이 검사하지 않으므로, 확인하려면 `doc-check` 스킬을 부릅니다
